# 模型与思考强度

思考强度与模型是两个独立设置。调强度会改变当前模型处理后续请求时的推理投入，不会自动更换模型、Key、网关或对话 ID；已经发出的请求不会被重新执行。具体档位和效果取决于客户端版本、模型和上游，同名档位不代表同样的思考量、Token 或价格。

| 操作 | 当前会话 | 工作台处理方式 |
| --- | --- | --- |
| 调思考强度 | 客户端与上游支持时可修改 | 当前终端入口填入原生命令，确认后发送；不因此创建分支 |
| 同一 Key、网关和兼容协议下换模型 | 可由 CLI 原生 `/model` 修改 | 当前模型以 CLI 显示为准，外层模型选择是启动配置 |
| 换 Key、网关或协议 | 不作为运行中会话的快捷操作 | 新建会话，或在原项目从历史创建分支 |
| Claude 与 Codex 互换 | 不是切换模型 | 两个客户端使用各自历史格式，分别启动 |

## 两个入口

- **启动默认思考强度**：在模型设置附近，按客户端、调用配置和模型分别保存。选择「客户端默认」时不额外指定参数，保留 CLI 已有配置。系统 CLI 启动继续沿用外部配置。手机连接电脑时，支持新版电脑启动参数；本地覆盖 Debian 与完整 Linux VM。
- **当前会话思考强度**：在目标终端旁，滑动到明确档位后点「填入当前终端」，检查 CLI 输入框再按回车。只填入命令，不自动提交、不清空草稿、不打断任务，也不把滑条目标冒充已生效值。选择「客户端默认」会打开原生设置菜单，并不代表已经清除当前强度。SSH 仍需持有该终端的输入控制权。

界面显示通用候选档位 default / low / medium / high / xhigh / max。它们不是服务商已认证的能力清单；未返回能力元数据的接口无法保证全部支持。上游拒绝某个档位时按其提示选择，并检查 CLI 确认结果。工作台不再统一强制 medium，也不再固定关闭 Claude 思考。

Codex 原生模型目录与网关 `/models` 列表是两个独立来源。本机 Codex 0.172 的 `/model --reasoning=...` 会先查原生目录，未收录的第三方模型会在本地报 `Model '...' is unavailable`，即使上游 API 允许调用。工作台不把网关 ID 列表伪造成能力目录。此时先为该客户端、Key 配置和模型设置启动强度，再自行结束原终端并按原配置恢复同一对话；强度通过启动参数覆盖，不改原会话 ID，不必创建分支。正在运行的旧进程不会读取新的启动设置。手机 SSH 的启动强度作用于新启动或已结束后恢复的电脑进程，已运行进程接续继续沿用其原设置。

智谱实测的 `glm-5.3` Responses 入口为 `https://open.bigmodel.cn/api/v1`，`high` 可完成流式请求；隔离环境中的实际 Codex 0.172 CLI 也已用启动参数 `high` 完成单轮回复。这个单轮连通性验证不表示所有工具、长上下文和模型档位都已验证。`low / high / max` 以服务商当次错误提示为准；`medium` 不适用于此次调用。

手机从电脑历史按原配置恢复时，只读取该来源配置的手机端强度偏好；「恢复最近对话」由电脑查找来源，沿用电脑原配置与默认设置，避免把手机当前选中的另一模型强度带入原对话。

## 原生命令

Codex 保留当前模型，只改强度：

```text
/model --reasoning=high
```

Claude 保留当前模型，只改强度：

```text
/effort high
```

模型切换使用各自原生 `/model`；第三方网关优先使用完整模型 ID。新模型必须可通过当前 Key 和协议调用，还需兼容已有上下文、工具及附件。历史上下文会发送给之后使用的模型，缓存命中与计费可能变化。外层启动配置不会替代 CLI 对运行中会话的确认。

原生命令的保存范围由 CLI 自己决定。尤其 Claude 的 `/effort`、`/model` 可能同时更新其默认设置；工作台隔离会话保存到隔离目录，系统 CLI 会话则可能影响该系统 CLI 之后的默认值。需要仅本次会话生效时，请使用该 CLI 版本提供的 session-only 选择，或通过工作台启动强度参数启动隔离会话。工作台不会为了滑条自动改写系统 CLI 配置，也不会注入回车执行命令。

官方行为依据：[Codex 交互命令](https://developers.openai.com/codex/cli/slash-commands)、[Claude 交互模式](https://code.claude.com/docs/en/interactive-mode)、[Claude 模型与 effort 配置](https://code.claude.com/docs/en/model-config)。命令支持范围和生效时点以安装的 CLI 版本为准。
