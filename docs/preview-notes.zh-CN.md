本次为三端测试版，可下载安装。配置、Key 与对话历史保存在原来的用户数据目录，更新不会主动重启正在运行的终端。

- macOS、Windows、Android 增加应用内检查更新、更新说明、下载校验与覆盖安装入口，支持发现远端测试版。
- 历史恢复按来源和配置判断：同一环境直接续接；跨环境或配置变化时复制并创建独立分支，保留来源记录。
- 左侧历史汇总可访问的对话，目录内恢复按所选工作目录筛选，并补充对话内容预览。
- macOS、Windows 提供全局 CLI 直接启动入口，沿用外部配置；工作台局部启动继续隔离配置。跨环境对话通过复制迁移，避免改写外部环境。
- 改进桌面端文件与图片拖入终端，以及终端复制粘贴体验。
- Android 提供 Termux、可选 Debian、完整 Linux 虚拟机和 SSH 环境入口；无 root 的 Android 本机能力受系统限制，需要完整 Linux 内核的功能可选择虚拟机或远端 SSH。

已知限制：本批未解决部分模型/兼容网关返回空工具参数、输出截断的问题；跨模型轻量中转仍在规划中。Windows 安装包尚未使用商业代码签名，Android 测试包使用固定开发签名。
