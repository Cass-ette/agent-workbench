本次为三端测试版，可以下载安装。覆盖升级保留配置、Key 与对话历史。

- 三端用量图改为独立绘制输入、输出：桌面并列柱、Android 分行条形，避免堆叠时较小的输出难以辨认。新增「输入与输出／仅看输入／仅看输出」，单独查看时按所选系列缩放；上方用量和费用汇总保持统计范围，颜色固定为输入蓝、输出橙。
- 三端新增「用量与费用」小窗：按项目完整路径、调用 Key 的配置档案、模型、Codex / Claude、会话和 UTC 日期组合筛选，可按项目／配置／模型／客户端／会话汇总，也可看每日柱状图，切换 Token 与费用。目录默认不含子目录，需主动勾选。Mac / Windows 点击底部用量摘要，Android 在配置页点「查看用量与费用」。每台设备统计自己的本地隔离日志，不加入设备维度。
- 费用只展示日志明确保留的上游 USD 金额或单价；未提供时不套参考价，不把 CLI 客户端估价当成实扣，不需要管理 Token。零费用与未提供分开，缺价时只合计已知部分。缓存读写、推理 Token 单独展示，但不重复累加到输入输出。响应片段、恢复和历史副本去重；累计快照按增量统计，保留各次调用的项目和模型。增加本机脱敏缓存，日志变化后重新扫描；CLI 没有保留的历史费用无法追溯。
- 三端支持兼容网关的自定义 API 前缀（例如 `/proxy/v1`、`/api/paas/v4`），Codex 不再固定追加 `/v1`；Claude 避免重复版本路径。模型目录可选，macOS / Windows 补上手动填写模型 ID，Android 保持同样入口。没有目录接口会明确提示 Key 尚未验证，鉴权、网络或重定向错误仍显示；也可取消「保存时读取模型列表」先保存。启动与恢复不再依赖目录白名单。Claude 仍需 Messages、Codex 仍需 Responses，未加入跨协议转换。保留现有根地址配置身份、Key 和历史。
- Mac / Windows 广播局域网服务，Android 在两端一起换 Wi-Fi 或热点后自动查找已配对电脑；再次核验 SSH 主机公钥后更新地址，保留原配对。只支持局域网；设备隔离、阻止组播的热点可能无法自动发现，可重新导入电脑当前的连接码更新地址。Mac 版本号已递增，避免与本机测试版同版本而无法检查更新。
- Android 本地、普通 SSH 和电脑接续终端增加「复制文本」「粘贴」。长按终端也可打开文本快照，支持选择部分文字或复制全部；只读会话也能复制。文本仅来自当前标签已加载的内容，软换行会合并，选文期间不受后续输出影响。
- 三端终端标签支持拖动排序。Android 长按标签标题后拖动，提供震动和半透明反馈，标签上可单独关闭并确认；修复标题被关闭按钮挤没的问题。重排保留当前会话与输入、附件目标；macOS 相邻标签向右拖动也能正常换位。
- 修复 macOS 工作台在终端持续输出后反复崩溃的问题：输出回调不再因反复读取而累积调用包装、耗尽 IO 线程栈；最近 1 MiB 输出改用固定环形缓冲。无需连接手机也能触发的路径已加入发布模式压力回归。
- Mac 系统 CLI 使用内嵌终端的真实类型，避免从其他程序启动工作台时继承 `TERM=dumb`，影响 Codex / Claude 交互界面。Android 重新导入同一电脑的连接码会核对主机公钥和账号，更新地址并保留配对；连接成功后清除旧的登录中提示。
- 手机接续电脑时，输入控制状态和输入失败只显示在对应终端；重新接续后清除旧提示，迟到的只读响应不会覆盖新控制权。新版电脑区分本机输入接管、控制权超时及其他设备控制；旧电脑仅显示中性只读提示。工具栏增加回车和方向键，原翻页按钮改为「上翻/下翻」，兼容输入法将普通回车提交为换行字符的情况，便于处理 Codex / Claude 终端审批。
- 修复 Android 连接电脑失败时登录标签立即消失、看似按钮无反应的问题。失败后保留终端与原因；电脑未启用接续、SSH 未开启、地址不可达和身份校验失败分别提示。连接中重复点击返回原登录终端，不再反复创建连接。
- 修复 Android 项目目录输入时键盘导致任务配置消失、失去焦点和滚动位置的问题；电脑目录可从已有项目中选择。历史窗口扩大并增加内容摘要和来源信息，过滤指令前言；恢复/接续后直接展示终端并说明项目。
- 新增手机接续电脑工作台的第一阶段测试功能：电脑「手机连接」启用后，Android 通过 SSH 查看并接续同一运行终端，使用电脑配置/系统 CLI、新建及恢复历史，支持传入 20 MB 内附件。关闭手机会话只断开，结束电脑任务需单独确认。Mac + 小米平板已验证同一进程接续、终端回车、电脑接管、后台超时和原配对更新地址；真实 Windows 接续仍待实机验收。工具设置与系统授权面板暂留在电脑端。详见手机接续说明。
- 修复部分 Android 设备无法启动 Termux 桥接、界面显示大段红色错误的问题。启动文件分段传输，不再受单个命令参数大小限制；准备失败时显示简短的重试提示。
- 修复 Mac 模型列表读取失败后无法继续选择模型或新建会话的问题。保留当前配置上次的模型和选择，按 Key 配置、网关分别缓存；空列表也能打开选择窗口查看失败原因并刷新。无可用历史选择时支持手动填写模型 ID，不借用其他网关的模型。终端「＋」与顶部启动按钮使用相同条件。
- Mac / Windows 补上微信等截图工具的剪贴板图片粘贴：保存为工作台私有 PNG 后交给当前对话，不自动提交。普通文本粘贴保持原行为；图片处理中切换或关闭标签会取消插入，避免串到其他对话。需要支持图片的模型和网关。
- 三端增加「工具与插件」入口，可分别接入工作台私有 MCP、Skills 和 Claude 本地插件。导入组件默认停用，确认保存后供后续新建、恢复和分支会话加载。外部客户端配置不变。Claude 最小模式的技能调用命令显示在列表中，完整插件 hooks 等能力仍受模式限制。
- 工具组件完整复制后才启用目标副本；Windows 保存失败保留原配置，拒绝无效超时。Claude 的环境变量凭据在 CLI 启动时读取，不展开保存到配置文件。Android 重连桥接期间锁定客户端和运行环境，失败会结束等待并显示原因。
- Mac / Windows 可启用主屏幕读取 MCP，供 Codex 和 Claude 调用。需要系统授权与支持图片的模型；不控制鼠标键盘。Android 按 Debian / Linux VM 分别配置工具，本机截屏尚未接入。详见工具接入说明。
- 三端首次启动显示 Codex / Claude 权限设置，并提供常驻入口。Codex 推荐项目内写入、允许联网和按需审批；Claude 推荐标准审批。高权限需明确确认，运行中的终端保持原权限；系统 CLI、SSH 沿用外部设置。
- 保留启动环境的代理及用户 NO_PROXY 规则，确保本地网关直连。macOS 不再清空 Claude 的代理；Android 向 Debian 传递 Termux 代理配置。权限、工具连接与应用账号授权分别管理。
- 修复 Windows 关闭终端后 Codex 仍在后台占用对话的问题。恢复仍在运行的原对话会切回已有标签。若标签正在关闭，工作台会等进程退出后再恢复。
- macOS 左侧调用配置现在可以删除自定义 Key；确认后同时删除该配置的本机 Key 和只读账单 Token，保留历史对话。默认免费配置不能删除；已有终端进程可能暂时仍持有已删除的 Key。
- 修复 macOS 和 Windows 切换终端标签后拖放可能串到上一个对话的问题。拖进终端的文件路径只会插入当前选中的 Codex 或 Claude 对话。
- Mac 左侧常驻「检查更新」入口，有更新时显示新版版本号；Windows 右上角继续提供常驻入口，无需在菜单中寻找。
- macOS、Windows 和 Android 优先读取固定更新清单。GitHub API 仅作为备用，检查失败会显示原因。`0.x.y` 显示为测试版，`1.0.0` 起显示为正式版，两者都可以通过应用下载安装。旧客户端如果仍找不到此次更新，可从本页手动覆盖安装一次。
- macOS 和 Windows 的左侧「恢复最近对话」可以浏览所有项目的最近对话，也可展开目录树查找。点击对话即用原配置恢复。
- 右侧「恢复最近对话」只看当前项目与客户端。「从历史创建分支」会用当前选定的配置创建独立会话。桌面启动方式显示为「工作台配置」或「系统 CLI」。
- Android 的 Debian 支持跨项目查找和在项目内恢复、创建分支。Linux VM 可恢复虚拟机里当前配置的历史。SSH 使用电脑上的历史。
- Mac 和 Windows 增加「手机连接」。Android 粘贴连接码后可打开 SSH 终端，首次登录时可由应用记住手机。电脑需开启系统 SSH 服务，手机接续仅支持同一局域网。

Windows 默认管理员账号使用密码登录。Windows 安装包尚未使用商业代码签名，Android 测试包使用固定开发签名。
