Agent Workbench 首个三端正式版。macOS、Windows、Android 统一为 **1.0.0**。

## 本版功能

- 在工作台私有配置中运行 Codex / Claude，支持自定义兼容网关、调用 Key、模型目录和启动思考强度；Mac / Windows 也可直接使用系统 CLI。
- 按项目浏览历史，用原配置恢复最近对话，或用当前配置创建独立分支；支持归档和取消归档。
- Catppuccin Latte / Mocha 浅深色主题与跟随系统；修复终端对话框对比度、Mac 项目标签拖动及持续输出引发的崩溃。
- Mac / Windows 支持当前对话的文件拖入和截图粘贴；支持私有 MCP、Skills，以及需要系统授权的主屏幕读取工具。
- 按项目、配置、模型、客户端、会话和日期查看本机用量。输入输出分别绘制；费用只显示上游日志实际提供的金额或单价。
- Android 提供 Termux / Debian、可选 Linux 虚拟机，以及同一局域网内接续电脑工作台。可查看电脑项目与历史、接续终端、申请输入控制、传附件、复制与粘贴文本。
- 三端提供应用内检查更新、安装包哈希校验和明确标红的高权限选项。

## 升级说明

- 可以从已有测试版覆盖升级，保留配置、Key、历史和已安装的运行环境。**不要先卸载旧版本。**
- Android 使用关闭调试的 release 构建，沿用此前公开测试包的固定签名证书，增加版本代码。更新清单同时兼容旧测试版和正式版的检查入口。
- Mac 包适用于 Apple Silicon 与 Intel；Windows 包适用于 x64；Android 为通用 APK。旧版本若无法检查到更新，可从本页下载对应安装包覆盖安装一次。

## 已知边界

- Mac 使用临时代码签名，尚未经过 Apple 公证；Windows 尚无商业代码签名，系统可能显示未知开发者提示。
- 手机接续限局域网。热点客户端隔离或组播限制可能影响自动发现，可重新导入电脑当前的连接码。Mac 与小米平板已经实机验证，Windows 接续仍待更多实机验收。
- Android 无 root 时无法获得完整宿主权限；Debian、Linux 虚拟机和 SSH 的能力取决于所选环境。屏幕读取暂限 Mac / Windows，系统授权仍须用户确认。
- 兼容网关仍须支持客户端使用的 API 协议；不同模型支持的思考档位、工具调用和图片能力由上游决定。运行中的任务不会因更新检查而重启。
