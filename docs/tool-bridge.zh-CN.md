# 工具与插件接入

macOS、Windows 侧栏的「工具与插件」和 Android 顶部「工具」用于配置工作台自己的工具。分别选择 Codex 或 Claude；Android 再选择 Debian 或 Linux VM。系统 CLI 与 SSH 继续使用外部或远端自己的工具配置。

## MCP

填写 MCP JSON，支持 Claude 的 `mcpServers` 和 Codex 的 `mcp_servers` 对象。只读取服务字段，不合并整个客户端配置，不导入模型、登录、历史或权限策略。macOS 也可以从 JSON 文件载入。服务名只使用字母、数字、下划线和连字符。

```json
{
  "mcpServers": {
    "local_tool": {
      "command": "/absolute/path/to/server",
      "args": ["--stdio"],
      "env": {}
    },
    "remote_tool": {
      "type": "http",
      "url": "https://your-service.example/mcp",
      "enabled": false
    }
  }
}
```

核对程序、参数、地址和组件后勾选确认并保存。保存不执行程序；之后新建、恢复和分支的工作台会话才加载配置。服务实际注册名加 `workbench_` 前缀。服务中设置 `enabled: false` 可停用；删除其 JSON 条目后保存可取消登记。运行中的会话保持已加载的工具，需要关闭对应会话才能停止已运行的服务。

支持 stdio 和 Streamable HTTP；旧 SSE 仅能用于 Claude，Codex 会说明不兼容。`headers` / `http_headers` 会按客户端转换。可使用 `env_vars`、`bearer_token_env_var` 或 `env_http_headers` 引用启动环境已有变量；变量必须在实际终端/来宾环境可见，图形应用不会自动取得别的应用的 token。Claude 的生成配置保留 `${变量名}` 引用，由 CLI 在启动时读取，不把环境变量中的 token 展开后存入历史配置文件；保存时不要求 GUI 已经取得该变量。Claude 不支持这里的服务级 `cwd`，请使用绝对程序路径。账号 OAuth 登录的图形管理仍未实现，可改用服务支持的独立凭据或原生登录流程。

配置在用户私有目录保存；本地编辑器会显示用户主动填入或导入的配置内容。不要把配置、认证头或截图贴入公开问题、日志或发布包。工具依赖需要在运行环境安装，注册成功不等于服务连接、系统授权或模型能力已验证。

## Skills 与 Claude 插件

选择包含 `SKILL.md` 的单个技能目录，或包含 `.claude-plugin/plugin.json` 的 Claude 插件目录。导入会复制到工作台私有目录，默认停用，不执行程序。勾选组件并确认保存后才在之后启动的会话中加载。停用不删除已有会话可能正在使用的文件。

Codex 使用私有 `CODEX_HOME/skills` 和原生技能开关。Claude 将独立技能注册为工作台私有插件，在列表中显示 `/命令`。Claude 的最小启动模式主要通过该命令使用技能，不保证自动注入所有技能描述；显式插件的 hooks、LSP、同步等能力仍受 CLI 的 `--bare` 模式限制。本次保持该模式以保留隔离认证和已验证的网关路由，不承诺完整插件的所有功能。

启用的 Claude 插件若包含 `.mcp.json` 或 manifest 的 `mcpServers` 配置，会登记其中兼容的服务到显式 MCP 配置，并将 `${CLAUDE_PLUGIN_ROOT}` 指向工作台副本；配置文件路径必须在插件副本内部。这样无需放开外部项目或系统 MCP 的自动加载。

只复制单个组件，不复制外部配置根目录、账号 token 或整个插件缓存。拒绝包含符号链接的组件，避免带入别的目录；单个组件上限 100 MB / 一万文件。组件先完整复制再发布到目标目录，复制失败可重新导入；Windows 保存配置先写临时文件，成功后才替换旧文件。更新时重新导入新副本、停用旧副本。批量扫描、依赖安装、OAuth 管理及一键更新/删除组件仍在 [#12](https://github.com/Cass-ette/agent-workbench/issues/12) 跟进。

## 屏幕读取

macOS / Windows 可勾选「启用本机屏幕读取」。工作台会给两个客户端注册 `capture_screen` MCP 工具，按调用返回当前主屏幕 PNG，不控制鼠标键盘。图片会进入所选模型和网关的请求，模型及接口须支持图片；启用不表示已验证图片能力。Mac 的临时截图在返回后删除，Windows 在内存生成；客户端自身可能记录工具结果，不承诺整个链路完全不留历史。

macOS 需要给实际负责操作的工作台或服务进程授予「屏幕录制」权限，可从工具设置打开对应系统设置。辅助功能授权另用于点击、输入等工具，两者互不替代，也不能继承另一款客户端应用的授权。本项目当前使用 ad-hoc 签名，升级后系统可能要求重新授权。

Windows 需要已解锁的交互桌面，不能读取 UAC 安全桌面。内置读取只截主屏幕并缩放至最长约 1600 像素；图像返回是否能被模型理解取决于模型和网关。浏览器或鼠标键盘控制可另行连接兼容 MCP，按服务要求授权。

Android 的 Debian 和 VM 可接 MCP、Skills 与 Claude 插件；组件路径分别是 Termux 或来宾系统内路径。内置 Android 屏幕捕获尚未实现，不能把 VM 权限当成手机截图授权。可以接入已授权的远端截图 MCP，读取的是服务所在机器的屏幕。SSH 的工具由远端电脑配置。

## 微信等截图工具粘贴

桌面 GUI 会接收剪贴板里的图片数据，终端通常只转发文字；截图不能粘贴不代表模型不支持图片。Mac 终端现在接收 PNG / TIFF 等剪贴板图片，转换为 PNG；Windows 接收 WebView2 提供的剪贴板图片，必要时转换为 PNG。先点击目标对话，再按 Mac ⌘V / Ctrl+V 或 Windows Ctrl+V。普通文本仍走原有粘贴，Finder 文件复制和拖放继续插入路径。

图片保存到工作台自己的附件目录，通过终端的粘贴协议交给当前 CLI，不自动回车或请求模型。Codex 可将图片路径显示为 `[Image #1]`；Claude 的显示方式取决于 CLI 版本，也可读取插入的图片路径。异步转换或保存期间切换、关闭标签会取消插入，请回到目标对话再粘贴。截图上限 20 MB / 4000 万像素。

这项操作不需要屏幕录制授权：用户已通过截图工具将图片复制到剪贴板。模型和网关仍须支持图片。Mac 附件位于 `~/.config/cchp-client/claude-test/attachments`，Windows 位于当前用户应用配置目录的 `attachments`，保留供会话稍后读取和历史使用；不自动上传或定期删除。手动删除后，旧路径将失效。SSH 的远端无法直接读取本机附件路径，需先传到远端；Android 本机剪贴板图片仍需单独接入，不能将终端文字粘贴等同于已支持图片附件。
